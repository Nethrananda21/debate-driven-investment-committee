# Debate-Driven Investment Committee

A small multi-agent project that recommends **BUY**, **HOLD**, or **AVOID** for an asset using documents you provide. It does not fetch live market data. The included Asteria Systems documents are fictional demo data.

## Workflow

1. Retrieve relevant passages from the asset's documents.
2. Research selects passages; Bull argues BUY and Bear argues AVOID.
3. Bull and Bear each rebut the other side once.
4. Judge decides using cited passages only.
5. Risk can override the Judge to HOLD when net debt to EBITDA exceeds the chosen threshold.

The dashboard shows each agent's turn, its response time, the final recommendation, and the cited sources.

## Setup and run

Use Python 3.11 or newer. In PowerShell, from this folder:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Put your NVIDIA NIM and Groq API keys in `.env`, then start the dashboard:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Enter the asset name and a folder containing `.md`, `.txt`, or `.pdf` documents, then click **Run debate**. The example folder is `documents/asteria`. To use the command line instead:

```powershell
.\.venv\Scripts\python.exe main.py "Asteria Systems" documents/asteria > output.json
```

The default veto threshold is **net debt to EBITDA > 3.0x**. Use `--max-net-debt-ebitda 4.0` on the command line or change the dashboard field to set another threshold.

## Files

| File | Purpose |
| --- | --- |
| `app.py` | Streamlit dashboard with one box per agent and a JSON download. |
| `main.py` | Debate order, model connections, citations, timing, risk override, and command line entry point. |
| `retrieval.py` | Reads asset documents, splits them into passages, and retrieves relevant passages with TF-IDF. |
| `agents/common.py` | Shared Semantic Kernel agent setup and JSON response helper. |
| `agents/research.py` | Research Agent: selects relevant source passages. |
| `agents/bull.py` | Bull Agent: BUY case and rebuttal. |
| `agents/bear.py` | Bear Agent: AVOID case and rebuttal. |
| `agents/judge.py` | Judge Agent: BUY, HOLD, or AVOID with cited reasons. |
| `agents/risk.py` | Risk Agent: checks the debt ratio and applies a HOLD veto. |
| `agents/__init__.py` | Marks `agents` as a Python package. |
| `documents/asteria/*.md` | Three fictional company, financial, and risk documents for the demo. |
| `tests/test_workflow.py` | Local checks for retrieval, citations, and the veto rule. |
| `requirements.txt` | Python dependencies. |
| `.env.example` | API key template; copy it to `.env`. |
| `.gitignore` | Excludes `.env`, the virtual environment, caches, and generated output. |

`output.json` is generated by a run and is not committed. The dashboard reloads the latest completed result from that file after a refresh. Citation IDs are checked against the document set, but a human should review the agent prose against the cited passages before relying on a recommendation.
